# Current known limitations

The current main branch contains the 56-realm, 576-district atlas; five on-demand management workspaces; dynasties, succession, marriage, court offices, government, diplomacy, factions, intrigue, economy, religion, heritage, naval transport/blockades, strategic AI and playable open-field tactical battles. The old 299-district map remains for legacy saves.

- Territory and district labels are historical-reference-aligned approximations. Many regions are independent and initial populations/economies are fictional balance values. No claim of historical accuracy.
- Tactical forces are represented by sampled animated soldiers, not one fully simulated individual per troop. Cavalry is procedural. Naval travel is abstract, not a real-time naval combat game. Sieges are excluded from the playable field battles by design.
- AI is deterministic rule-based. The content is substantial but does not replicate every Crusader Kings feature; balance and extended playtesting remain necessary.
- Single-player static browser game. Browser storage has device-specific quota; export a backup. Four map versions are supported, not arbitrary third-party maps.
- Earlier desktop/mobile Chromium campaign checks passed on a prior commit; direct-main changes require fresh regression and visual verification. Physical mobile device, Safari/Firefox, audio quality, frame rate, accessibility and long-duration performance need measured acceptance before public release.
- The project is not certified production-ready. See [release acceptance](RELEASE_ACCEPTANCE.md).
