# Runtime asset integration
The optional local battle score uses the existing user-uploaded `assets/audio/war theme.ogg`, starts only when combat begins, pauses with the simulation/mute/visibility and stops on exit. The original procedural effects remain independent. The score is not included in the publicly published playtest ZIP until its source and redistribution rights are recorded; absence or codec failure does not prevent combat.
The portrait, event illustration and icon source sheets must be visually identified before selecting crop coordinates. `scripts/inspect_art_sheets.py` creates contact sheets and reports GLB rig/animation metadata and archive contents. It does not automatically assign an arbitrary image to a historical character.
Do not import Kaliyuga VFX videos or unrelated documents into the strategy game. New character models require rig, scale, animation and licensing checks; heraldry requires correct historical identity. Natural Earth shading is not scientific elevation.
