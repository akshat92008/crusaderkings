# Uploaded gameplay artwork

50 unique sheets were visually reviewed (55 uploads, five exact duplicates). 536 optimized WebP tiles: 256 portraits, 84 event illustrations, 64 realm emblems, 64 dynasty emblems and 68 UI pieces. Six verified 4×4 gameplay icon sheets remain sprite sheets. Source PNGs remain untouched; regenerate with `python -m pip install Pillow && python scripts/build_game_art.py`.

The art is illustrative alternate-history game art, not verified historical heraldry or portraits. Unknown or unmatched cultures and children retain a fallback. Not every extracted decorative piece is used yet; event art is selected by theme, not a literal account of historical events. The seventh icon sheet and any unverified licensing assets are not activated. The war-table video is muted, pauses outside the menu and honors reduced motion.
